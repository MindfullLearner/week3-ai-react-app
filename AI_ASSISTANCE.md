## 🤖 AI Tools Used

### Cursor

Cursor was used during the early stages of BookFinder development.

It was used for:

- Understanding the initial project requirements
- Creating the initial project structure
- Generating the first few implementation files
- Assisting with the initial MVVM architecture
- Providing code suggestions while working directly inside the project
- Making early project configuration changes
- Helping implement the initial application functionality

Cursor was used directly within the project codebase, allowing AI-assisted code generation and modification while working on the application.

---

### Claude

Claude was primarily used during the later stages of development.

It was used for:

- Creating and extending the MVVM structure
- Implementing the Open Library API service
- Implementing Home Model, ViewModel, and View
- Implementing Favourites Model, ViewModel, and View
- Configuring Firebase
- Implementing Firebase Realtime Database operations
- Implementing user authentication
- Creating the authentication context
- Updating application routing
- Implementing protected routes
- Moving business logic from views into ViewModels
- Updating favourites to be stored per authenticated user
- Implementing Login and Logout functionality
- Debugging and fixing implementation errors
- Updating project documentation

---

### ChatGPT

ChatGPT was used primarily as a development mentor and troubleshooting assistant.

It was used for:

- Understanding project requirements before implementation
- Explaining MVVM architecture and development concepts
- Explaining Firebase and authentication concepts
- Reviewing AI-generated code
- Diagnosing errors from the browser console and terminal
- Explaining why implementation errors occurred
- Creating and improving prompts for Claude
- Reviewing project structure
- Suggesting conventional Git commit messages
- Guiding testing and verification
- Preparing project documentation
